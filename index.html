the ai under the hood

an agent pipeline,
not a chatbot.

powered by Claude, by Anthropic

Every backtrace runs through an orchestrated pipeline built on Claude, Anthropic's AI model. Each stage has one job and returns structured output, and each result is checked before the next stage runs.

  1. 01

    Triage

    Parses the signal, frames, threads and language straight from the GDB output — no model guesswork for what the stack already says.

    deterministic
  2. 02

    File Advisor agent

    Reads the backtrace and asks for only the source files the crash actually touches, so the model sees signal, not your whole repo.

    context selection
  3. 03

    Root-cause reasoning

    Claude reasons over the frames and source, then returns schema-checked JSON: the buggy line, a corrected line, confidence, and what evidence is still missing.

    claude · structured reasoning
  4. 04

    Fix Validation agent

    Reviews the proposed fix like a senior engineer — races, ownership, regressions — before you ever apply it.

    safe · caution · unsafe
  5. 05

    Correlation engine

    Matches the crash against your team's history. Fixes engineers confirmed rank first; disputed ones are penalised.

    team memory
